Salon Appointment Booking

A simple web app for booking appointments at a hair salon


What it does
Shows a list of all appointments (sorted by date)
Lets you book a new appointment with a form
Rejects a booking if the time is already taken
Validates the form (required fields, 10-digit phone, date must be in the future)
Calculates the end time automatically from the service duration
Technologies
Java 17
Spring Boot (Web, Data JPA, Validation)
Thymeleaf
H2 database (in-memory)
JUnit and Mockito
Maven
